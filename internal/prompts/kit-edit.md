# This page uses the Faz kit

The page is written with Tailwind classes and the kit components below, with its identity in the `<style type="text/tailwindcss">` block, which is compiled after you answer. Keep it that way:

- Change colors and fonts by editing the `--color-*` and `--font-*` tokens in that block, in every theme it defines, never with raw colors in classes.
- Build anything new from the kit components and utilities. Do not add other `<style>` elements or CSS files.
- Icons are `<i data-icon="name" class="size-4"></i>` with names from the list.
